## The experiment

We asked one Research Factory to build a Reflexion implementation from scratch
inside its own project git workspace. The Factory did not execute or copy the
reference cookbook. It created persistent memory, retrieval, reflection,
injection, rollout, and per-experiment code, then improved the same instance
across B0, C1, and C2.
